# minireport3

上岡研 3年生ゼミ 2026後期のミニ研究（3人チーム：watanabe / tsukahara / yamashige）。

## 進め方
1. サーベイ論文を読む ← いまここ
2. 分野内の社会的な問題を考える
3. 解決に必要な技術を考える
4. 実証用のデータセットを決める（公開データセットが必須。人工データの生成はOK、APIは推奨）

成果物：プレゼン資料 / デモ / 論文（5ページ程度）

## フォルダ
- `survey/` サーベイ論文のまとめ（1人1ファイル：`survey/<名前>.md`）

## ルール
- main に直接 push しない。自分のブランチで書いて PR を出す
- PR は他の2人のどちらかが見てからマージする
- 論文のPDFそのものは入れない（著作権）。タイトル・URL・DOIを書く
