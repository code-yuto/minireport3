# 先行研究まとめ（yamashige）

## テーマ案
- テーマ：伝統工芸品のデータ整形とスマホ活用（背景の近道とラベルノイズの除去）
- もとになる社会課題：文化財のデータ化におけるラベル付けの手間と、美術館データから実環境（スマホ写真）へ持ち出す際の精度の低下

## 1. 先行研究のまとめ

### 論文1
- タイトル：Confident Learning: Estimating Uncertainty in Dataset Labels
- 著者・年：Northcutt, Jiang, Chuang (2021)
- URL / DOI：https://doi.org/10.1613/jair.1.12125
- 何をしたか：モデルの予測ではなくラベルの質に注目し、データセット中のラベルの誤りを特定・除去する手法（Confident Learning）を提案した。
- 結果（数字があれば数字で）：CIFARでは比較した7手法を上回り、ImageNetでは「missile」の画像のうち645枚が親クラス「projectile」として誤ってラベル付けされていることを推定した。
- 自分のテーマとの違い：論文では単一ドメイン内でのノイズ除去を扱っているが、本研究では「背景という近道（ショートカット）」の影響や、「美術館から実環境への持ち出し（ドメインシフト）」における効果を検証する点が異なる。

### まとめ：どこまで研究が進んでいるか
- データセットのラベルノイズを直接推定・除去するアルゴリズムは確立されているが、画像の見た目（背景など）に依存する誤りや、ドメインシフトへの有効性は十分に議論されていない。

## 2. 技術的な課題のあら捜し

| 課題 | どの論文の話か | なぜ問題か |
| --- | --- | --- |
| 誤りがクラスのみに依存するという仮定が強い | 論文1 | モデルが背景などの近道を学習していると、その近道に沿った誤りは確率が高く出てしまい、検出されないから。 |
| 除去したデータが別の撮影条件で有効か未評価 | 論文1 | 美術館のデータできれいに学習できても、実環境のスマホ写真で精度が出るとは限らないから。 |
| クラスの重なりを分離する仕組みがない | 論文1 | 検出された「誤り」に、意味的な重なりや珍しい正しい例が混ざってしまい、多様性を損なう恐れがあるから。 |

## 3. 新規性
- モデルを固定してデータ側のみを操作し、(a) 背景の有無とラベルノイズ除去を組み合わせて、美術館の写真から実環境への持ち出しにおける精度の落ち方を比較する。
- (b) 背景の有無によって検出集合がどう変わるかを調べ、近道に影響された検出の可能性を示す。
- (c) ラベルの粒度を変えたときの非対角成分が、分類の階層と対応するかを調べる。

## 4. 有効性
- 何が良くなるか：専門家が全データを見直さず、検出候補だけを確認すればよくなる。「近道に乗った誤りは検出できない」ことを示せれば、工芸品以外のデータ整備にも通じる注意点となる。
- 評価の指標：実環境テストセットに対する正答率（macro-F1）と、除去された集合の差分（Jaccard係数など）。
