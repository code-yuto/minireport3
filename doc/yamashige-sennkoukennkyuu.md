# 先行研究まとめ（yamashige）

## テーマ案
- テーマ：伝統工芸品のデータ整形とスマホ活用（背景の近道とラベルノイズの除去）
- もとになる社会課題：文化財のデータ化において、既存のラベルの誤りを点検する手間がかかることと、美術館のきれいな写真から実環境（スマホ写真）へ持ち出す際に精度が落ちること
- 本研究の焦点：工芸品のデータ整備には、(1) ラベルを新たに付ける段階と、(2) すでに付いているラベルの誤りを点検する段階がある。本研究は、時間と人手の制約から (2) に焦点を当てる。(1) は今後の課題とする。

## 1. 先行研究のまとめ

### 論文1
- タイトル：Confident Learning: Estimating Uncertainty in Dataset Labels
- 著者・年：Northcutt, Jiang, Chuang (2021) / Journal of Artificial Intelligence Research 70
- URL / DOI：https://doi.org/10.1613/jair.1.12125 （※要確認）
- 何をしたか：モデルの予測ではなくラベルの質に注目し、データセット中のラベルの誤りを特定・除去する手法（Confident Learning）を提案した。
- 結果（数字があれば数字で）：CIFARでは比較した7手法を上回り、ImageNetでは「missile」の画像のうち645枚が親クラス「projectile」として誤ってラベル付けされていると推定した。
- 自分のテーマとの違い：論文は単一ドメイン内でのノイズ除去を扱っている。本研究は、(a) 背景という近道の影響、(b) 美術館から実環境への持ち出し（ドメインシフト）での効果を検証する。また、ラベルを新たに付ける段階ではなく、既存ラベルの点検に焦点を当てる。

### まとめ：どこまで研究が進んでいるか
- ラベルノイズを推定・除去するアルゴリズムは確立され、美術館データへの適用も大規模には試みられている。一方、画像の見た目（背景など）に依存する誤りへの影響や、除去したデータが別の撮影条件で有効かは、十分に議論されていない（※調査の範囲内）。

## 2. 技術的な課題のあら捜し

| 課題 | どの論文の話か | なぜ問題か |
| --- | --- | --- |
| 誤りがクラスのみに依存するという仮定が強い | 論文1 | 実際の誤りは画像の見た目にも依存する（陶器と磁器の境目、用語の揺れなど）ため、仮定が当てはまらない場合がある。 |
| 背景などの近道に沿った誤りは検出されにくい | 論文1 | モデルが背景を手がかりに学習していると、その誤りでも確率が高く出て、誤りと判定されない。 |
| 除去したデータが別の撮影条件で有効か未評価 | 論文1 | 美術館のデータで精度が出ても、実環境のスマホ写真で出るとは限らない。 |
| 評価が大規模データ中心 | 論文1 | CIFAR や ImageNet が中心で、数百枚規模での検出の信頼性は確認されていない。 |
| 検出された「誤り」に、重なりや珍しい正しい例が混ざる | 論文1 | 除去すると多様性を損なう恐れがある。※今回は扱わない（今後の課題） |

## 3. 新規性
- モデルを固定してデータ側のみを操作し、(a) 背景処理（なし / 削除）とラベルノイズ除去（なし / CL）の4条件、および同じ枚数をランダムに除去する対照を比べ、美術館の写真から実環境への持ち出しにおける精度の落ち方を調べる。
- (b) 背景の有無によって、CLが検出する集合がどう変わるかを調べ、近道に影響された検出の可能性を示す。
- (c) ラベルの誤りを人工的に混ぜて、検出率と適合率を測る。
- 今後の課題：ラベルの粒度と非対角成分の対応（階層的な重なり）、およびラベルを新たに付ける手順の比較。

## 4. 有効性
- 何が良くなるか：専門家が全データを見直さず、検出された候補だけを確認すればよくなる可能性がある（本研究では直接は検証しない）。近道に影響された検出が起きることが示せれば、工芸品以外のデータ整備にも通じる注意点となる。
- 評価の指標：実環境テストセットに対する正答率（macro-F1）、美術館内テストとの差、混ぜた誤りの検出率・適合率、除去された集合の重なり（Jaccard係数など）。
