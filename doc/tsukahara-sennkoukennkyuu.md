# 先行研究まとめ（tsukahara）

## テーマ案
- テーマ：災害時の冠水道路画像を用いた水深推定と車両別の通行可否判定
- もとになる社会課題：最近、大雨が多く、浸水してしまっている地域(特に千葉)が多数ある。浸水してしまった道路を車やバイクが通れるかが分からない。

## 1. 先行研究のまとめ
1本ずつ、同じ形で書く。論文の PDF は置かず、URL か DOI を書く。

### 論文1
- タイトル：Automated Flood Depth Estimation on Roadways 
- 著者・年：:Kwame Ampofo, Megan Witherow, Alex Glandon, Monibor Rahman, Ahmed Temtam, Mecit Cetin, Khan M. Iftekharuddin,Proc. SPIE 13136, 1313603,2024
- URL / DOI：https://digitalcommons.odu.edu/cgi/viewcontent.cgi?article=1118&context=cee_fac_pubs
- 何をしたか：データ自動生成+車のスケール正規化+学習ベースの水深分類。  
  提案：COCOという大規模データセットから車だけを切り抜き、224×224ピクセルに拡大・縮小し、サイズを揃える。VGG-16というAIが4つの水位クラスに分類して出力。  
  実験：生成画像2988枚と実画像447枚で学習。別に用意した実画像334枚でテスト。スケール正規化の有無、学習データの種類を変更して実験。  
  | クラス | 水深 | 意味 |  
  | --- | --- | --- |
  | Level0 | 0-10cm | 浸水なし |  
  | Level1 | 11-30cm | 浅い |
  | Level2 | 31-50cm | 中程度 |
  | Level3 | 51-70cm | 深い |
- 結果（数字があれば数字で）：学習時はAccuracy 85%・F1 88%、検証はAccuracy 75.51%・F1 75.49%、テストはAccuracy 74.85%・F1 74.32%だった。  
  | 学習データ | 正規化なし | 正規化あり |
  | --- | --- | --- |
  | 実画像のみ | 54.8% | 65.57% |
  | 生成画像のみ | 33.3%(検証F1は91.2%) | 67.66% |
  | 混合 | 54.69%(検証F1は82.01%) | 74.32% |  

  どの場合もスケール正規化は有効。混合かつ正規化ありが最も良い結果だった。Fig.2の定性結果は、5例中4例が正解で、最後のSUV画像(正解Level 3)はLevel 0と誤判定された。車の向きと、手前と奥で水深が異なることが原因と考えられる。
- 自分のテーマとの違い：車両別の通行可否判定を扱っていない。自動車のみの判定。

### 論文2
- タイトル：The impact of flooding on road transport: A depth-disruption function
- 著者・年：Maria Pregnolato, Alistair Ford, Sean M. Wilkinson, Richard J. Dawson, Transportation Research Part D 55, 67–81, 23 June 2017
- URL / DOI：https://research-information.bris.ac.uk/ws/files/191868409/Full_text_PDF_final_published_version_.pdf
- 何をしたか：冠水深と車両速度の関係を作る。観測・シミュレーション・模型実験の既存研究と、動画解析を統合し、水深から安全に走れる最高速度を表す曲線を作成(水深0mmで88km/h,300mmで0)。乗用車の安全走行の上限を30cmとし、30cm以上は通行不可と仮定。また基本的に2WD車が対象で4WDは45cm～90cmまで走行可で小型車は15cmでエンジン停止の可能性あり。  
実験内容：1.駐車車両が浮く水深の実験結果と、雨による速度低下の研究結果を使って、曲線の両端を決めた。  
　　　　　2.動画解析は、水深を車輪の水没割合から推定し、速度を道路標示間の距離と経過時間から推定。(冠水路を走る車の動画から)  
　　　　　3.実際の洪水への適用(2012年6月28日 ニューカッスル洪水)：交通量計(ATC)のデータを、普段の木曜日と比べた。
- 結果（数字があれば数字で）：1.曲線(x軸水深、y軸降雨による速度低下)の結果：
  | 水深(mm) | 許容速度(km/h) | 出典の種類 |  
  | --- | --- | --- |
  | 0 | 88 | 文献 |  
  | 10 | 77 | 式 |
  | 87 | 40 | 動画 |
  | 125 | 26 | 動画 |
  | 200 | 16 | 試験シナリオ |
  | 230 | 7 | 助言記事 |
  | 250 | 3 | 助言記事 |
  | 300 | 0 | 複数の情報源 |  

  このグラフから曲線は右下がり。小型車は左寄りで4WDは右寄り。当てはまりの良さR^2=0.95であった。式にw=300mmを代入したところ約2.1km/hで表と誤差があった。  
  2.交通量のグラフの結果：洪水が始まった午後3前に、交通量が一時的に増えた。1時間後に交通量が基準より大きく減り、水が引くと戻った。しかし、センサーは車の台数しか数えず、水深も速度も分からない。→曲線の改善には使えない。
- 自分のテーマとの違い：自動車のみの判定。冠水領域や水深測定が人手を用いた動画。

### 論文3
- タイトル：冠水時の自動車通行の危険性に関する研究
- 著者・年：押川英夫、大島崇史、小松利光,河川技術論文集, 第17巻, pp.461–466, 2011年7月
- URL / DOI：https://www.jstage.jst.go.jp/article/river/17/0/17_461/_pdf/-char/ja
- 何をしたか：冠水した道路をどのくらいの水深・流れの速さで車が流されるのかを知る。  
提案：1.模型実験で水が車を押す力を測る。流れが車を押す力と上下にかかる力をセンサーで測る。車を流れに直角に置く。  
　　　2.実車で流されるかを計算する。流れが押す力Fと、車が耐える力R(タイヤと路面の摩擦力)の比を、Ψ=F/Rとし、Ψ>1なら流されると判定する。荷物・人の重さM:100〜500 kg、  
　　　摩擦係数μ:0.4〜0.6(基準0.5)、車内に水が入る空間の割合(空隙率)p:0〜0.5(基準0.2)を計算に使用。  
実験：長さ22 m、幅60 cm、深さ60 cmの直線水路を使用。  
　　　小型車は水深1.0〜3.0 cm、SUVは2.0〜4.5 cmの範囲で、流速を3通りずつ変えて測定。  
　　　模型の水深を実車の高さに対する割合(相対水深 h/k、kは車高)で表している。測定は100Hzで2分間の平均。
- 結果（数字があれば数字で）：主な結果(M=100 kg, p=0.2, μ=0.5)を以下に示す。  

| 項目 | 小型車 | SUV | 意味 | 
| --- | --- | --- | --- |
| Ψが急増(R=0,浮き始めの状態) | h/k≒0.27 | h/k≒0.39 | SUVの方が浮きにくい | 
| 流速U=2.0m/s超で流される水深 | h/k≒0.21(32cm) | h/k≒0.31(59cm) | 流速の増加で危険水深が大きく低下 | 
| 最悪条件(p=0,μ=0.4,流速2.5m/s超)で流される水深 | 26cm | 48cm | 悪条件が重なると膝程度でも危険 |
| 積載物M,摩擦係数μの影響 | 大きい,小さい | 小さい | 小型車は積載量の影響を強く受け、摩擦係数は車種で異なる |  

　　・空隙率pが0と0.5では、流される水深が小型車で約11 cm、SUVで約15 cm変わる(図10,11)。荷物が増えると危険度は下がる。(図12)  
　　・小型車の浮き始め(約41 cm)は、長崎水害で「ドアの上10〜20 cmで浮き始めた」という報告と合うため、計算は妥当とされている。
  
- 自分のテーマとの違い：自動車のみの判定だが小型や4WDの違いの判定はしている。冠水領域や水深推定に画像を用いていない。

### まとめ：どこまで研究が進んでいるか
- 論文1：「本物の冠水画像が少ない」という問題を、車の切り抜きによる疑似データと、スケール正規化と混合学習により、水深を4段階に約74%の精度で分類できた。  
ラベル不足を自動生成で補う設計が明快で、アブレーションが領域ギャップ(生成画像のみ:検証91.2%/テスト33.3%)を示している点。  
  論文2：「通れる、通れない」ではなく、水深が増えるほど安全に走れる速度が下がることを、式で表している。通行可否を二値から連続的な扱いへと進めている点と水深以外(降雨、運転者)の不確実性を示している。  
  論文3：小型車は遙かに流されやすい。流速・空隙率・積載量が危険度に大きく影響する。  
  →危険水深を物理量(力の釣り合い)で説明でき、車種・積載・空隙率の感度も分かる。市民向けの判読図まで落とし込んでいる。  
  水深・流速・車種から「流される」条件を物理的に示せる。

| 通行可否、車種を扱わない | 論文1 | 判断や行動につながらない(判定して終わりになっている) |

## 3. 新規性
先行研究に「ない」こと。
- 3つの論文を繋げれば、画像→水深→通行可否の流れの部品は揃う。  
　不足点：画像推定と車種別の通行可否判断の接続、二輪車の扱い、水深と流速の両方を考慮した画像ベースの判断。
- 新規性：1.水深測定結果と車種別の通行可否基準の接続。画像から水深を推定し、車種別の閾値を用いて「通行可/注意/不可」の3段階で出力する。  
　　　　　閾値は2と3を参考に、二輪車の基準を別途調査して設定する。(二輪車の根拠データがこの3本にはなく、別資料が必要)  
　　　　　必要なもの・追加調査：車種別の通行限界の資料、水深データ、判定ルール・二輪車の冠水走行・浸水限界、JAFなどの実験資料  
　　　　2.連続値または細粒度の水深推定と、基準物の拡張    
　　　　　順序回帰や連続値回帰、車種別の高さ・タイヤ径の利用、人や標識など車以外の基準物の併用。  
　　　　　必要なもの：基準物の実寸情報、細かい水深の正解データ。  
　　　　3.流れの有無の判別と安全側の判定  
　　　　　画像から「流れあり/なし/不明」を分類し、流れありや不明の場合はより厳しい閾値を使う。  
　　　　　難しさ・追加調査：流れの有無を判断できる正解データの用意が難しい。実現性は中〜低・画像・動画からの流速推定、流れを含む水面特徴の研究  
　　　　4.合成データの現実性向上と、日本の災害画像での検証  
　　　　　二輪車を含む生成(COCOに二輪車クラスがあるので同様の生成が可能か、要確認)、視点・水面表現の改善、日本の災害画像での評価。  
　　　　　難しさ:日本の冠水画像の収集とラベル付け。  
まとめ：最も自然なのは1(接続)を軸にし、2を水深推定部分の改良として組み合わせる案
