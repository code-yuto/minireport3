## 0. 先に知っておく言葉

| 言葉 | 意味 |
| --- | --- |
| 画像分類 | 画像を見て「これは猫」「これは車」のように、決まったクラス（種類）のどれかに分けること |
| クラス | 分ける先の種類。例：犬の品種なら「柴犬」「プードル」…がそれぞれ1クラス |
| データセット | 学習やテストに使う画像と、その正解ラベル（「この画像は猫」など）のセット |
| 深層学習（ディープラーニング） | たくさんの層を重ねたニューラルネットワークで学習する方法 |
| パラメータ（重み） | モデルの中にある調整できる数値。学習とは、この数値を正解に近づくよう少しずつ直すこと。数が多いほど表現力は高いが、データもたくさん必要 |
| CNN（畳み込みニューラルネットワーク） | 画像の小さい範囲（例：3×3ピクセル）を少しずつずらしながら見て特徴をつかむモデル。2012年ごろから画像分類の定番。ResNet、EfficientNet など |
| Transformer | もとは文章（翻訳など）のために作られたモデル。「Attention（注意）」という仕組みで、離れた部分どうしの関係も一度に見られる |
| ViT（Vision Transformer） | Transformer を画像に使ったもの。画像を小さいタイル（パッチ）に切って、文章の単語のように並べて扱う |
| 事前学習 | 大きなデータセットで先にモデルを学習させておくこと |
| ファインチューニング | 事前学習したモデルを、自分の目的のデータで少しだけ学習し直すこと |
| 転移学習 | 事前学習 → ファインチューニングの流れで、ある問題で学んだ知識を別の問題に使うこと。「英語を知っている人はフランス語を覚えやすい」のと同じ考え方 |
| ソース / ターゲット | ソース＝事前学習に使うデータ（大きい）。ターゲット＝本当に解きたい問題のデータ（小さいことが多い） |
| 過学習 | 学習データを丸暗記してしまい、新しいデータでは当たらなくなること。データが少ないと起きやすい |
| 自己教師あり学習 | 正解ラベルなしで学習する方法。例：画像の一部を隠して、隠した部分を当てさせる |
| Top-1 精度 | モデルが「一番自信がある」と答えたクラスが正解だった割合（%） |
| FLOPs | 1枚の画像を処理するのに必要な計算量。小さいほど軽くて速い（G＝10億回） |

## 論文1：Deep transfer learning for image classification: a survey

### 論文の情報
- タイトル：Deep transfer learning for image classification: a survey（画像分類のための深層転移学習：サーベイ）
- 著者：Jo Plested, Musa Phiri, Tom Gedeon
- 掲載：Artificial Intelligence Review, Vol. 59, Issue 3, Article 100（2026年1月29日公開）
- URL：https://link.springer.com/article/10.1007/s10462-026-11491-z
- DOI：https://doi.org/10.1007/s10462-026-11491-z
- ライセンス：Open Access（CC BY 4.0）。誰でも無料で読めます

### 1. 論文の要約

**どんな悩みを扱っているか**
- 画像分類の深層学習は、正解ラベル付きの画像が何十万〜何億枚もあるときに一番よく当たる。
- しかし現実には、そんなに集められない場面が多い。
  - 医療画像のように、そもそも数が少ない・プライバシーの問題がある
  - ロボットのように、データを集めるのにお金と時間がかかる
  - 自動運転の「緊急時」のように、めったに起きない場面がある
- そこで使われるのが**転移学習**（大きいデータで事前学習 → 小さいデータでファインチューニング）。

**この論文が言っていること**
- 転移学習がうまくいくかどうかは、次の **2つ** でほぼ決まる。
  1. **ターゲットの大きさ**：小さい（約1万枚）〜大きい（100万枚以上）
  2. **ソースとターゲットの似ている度合い**：例えば、ImageNet（一般的な写真）から犬・猫の品種に移るのは「似ている」。ImageNet から医療画像に移るのは「似ていない」
- これまでの研究は「似ていて、小さい」場合ばかり調べていて、「似ていない」場合にはうまくいかない方法が多い。
- **負の転移**：事前学習したせいで、かえって精度が下がること。次の3つがそろうと起きやすい。
  1. ターゲットが、ゼロから学習できるくらい大きい
  2. ソースとターゲットが似ていない
  3. 事前学習で覚えた重みを、十分に動かせない設定になっている
- **結論**：転移学習を「する / しない」の二択で考えるのをやめる。「何層ぶん・どれくらい強く転移するか」を、大きさと似ている度合いに合わせて調整すれば、負の転移はなくせる。

**実験でわかったこと（論文の 3.4 節）**
- 有名な手法 Big Transfer（BiT）のおすすめ設定は、ImageNet に似ている CIFAR・Oxford Pets ではよく当たる。
- 似ていない Stanford Cars（車種）・FGVC Aircraft（飛行機の機種）では、その設定だと最適から遠い。
- 似ていないデータほど、設定（学習率など）の影響を強く受ける。

**手法の分け方（論文が作った新しい分類）**

| 種類 | 何をするか | 例 |
| --- | --- | --- |
| インスタンスベース | どのデータで事前学習するかを工夫する | 似ているデータを選ぶ、自己教師あり学習 |
| 特徴ベース | ソースとターゲットの特徴をそろえる | MMD、敵対的学習 |
| パラメータベース | 重みの学習のしかたを工夫する | PETL、正則化（L2-SP、DELTA、BSS）、正規化、アンサンブル |
| ベストプラクティス | 設定の選び方のコツ | 事前学習データの選び方、学習率、転移しやすさの指標 |

**事前学習データの選び方のおすすめ順（論文の 4.2 節）**
1. ターゲットにとても似ていて、ずっと大きい、ラベル付きデータで学習
2. 似ていて大きい、ゆるいラベル（ハッシュタグなど）付きデータで学習
3. 似ていて大きい、ラベルなしデータで自己教師あり学習
4. ターゲット自身でラベルなしの事前学習（self-training）
5. あまり似ていないデータで自己教師あり学習
6. あまり似ていないデータでラベル付き学習（一番おすすめしない）

### 2. 歴史・流れ

| 年 | できごと | ポイント |
| --- | --- | --- |
| 2009 | Pan & Yang が転移学習の定義を整理。ImageNet（約130万枚）が登場 | 今も使われる「ソース / ターゲット」の考え方ができる |
| 2012〜 | CNN（AlexNet など）が ImageNet で大成功 | 「ImageNet で事前学習 → 小さいデータでファインチューニング」が定番になる |
| 2014 | Yosinski et al. の研究 | 下の層は「線・色」のような汎用的な特徴、上の層はタスク専用の特徴を学ぶ。層を固定するより、ファインチューニングしたほうがよい |
| 2017〜2020 | 事前学習データの巨大化 | JFT-300M（3億枚）、Instagram（35億枚）、Big Transfer。データが多いほど転移先も当たる |
| 2018〜2021 | 転移学習専用の工夫が多く出る | L2-SP、DELTA、BSS など。ただし「似ている」ときしか効かないものが多い |
| 2020〜 | Vision Transformer（ViT）の登場 | パラメータが多いので、事前学習データの量がさらに大事になる（→ 論文2） |
| 2020〜 | 自己教師あり学習が伸びる | 画像の75%を隠して当てさせる MAE（2022）など。ラベルなしでも事前学習できる |
| 2022〜今 | 巨大な基盤モデルの時代 | 全部を学習し直すのは重いので、一部だけ学習する **PETL**（Prompt、Adapter、LoRA 系）が中心 |

### 3. 社会的課題とのつながり
データを集められないこと自体が、社会の課題になっている分野がたくさんある。転移学習はその解決に欠かせない技術。
- **医療画像**
  - データが少ない（めずらしい病気、プライバシー）
  - 普通の写真と見た目が大きく違うので、似ている事前学習データがない
  - 病院ごとに撮影機器や患者さんの層が違い、別の病院では精度が落ちる
- **ロボット**
  - 実物のロボットは高く、データ集めに時間がかかる
  - シミュレーションで大量に学習し、少しの実データで仕上げる
- **自動運転**
  - 普段の運転データはたくさんあるが、事故寸前のような場面はめったにない
- **防災・環境**
  - 衛星画像から、山火事が自分で積乱雲を作って広がり方が読めなくなる「PyroCb」になるかを予測する
  - 衛星画像は大量にあるのに、その現象はめずらしく、ラベル付きデータがほとんどない
- **農業**
  - 作物の分類、収穫量の予測、害虫の発見
  - 「この害虫」のラベル付き画像はとても少ない
- **電力・環境負荷**
  - 大きいモデルをゼロから学習すると、大量の電力を使う
  - 転移学習なら、それを減らせる

## 論文2：Vision Transformers for Image Classification: A Comparative Survey

### 論文の情報
- タイトル：Vision Transformers for Image Classification: A Comparative Survey（画像分類のための Vision Transformer：比較サーベイ）
- 著者：Yaoli Wang, Yaojun Deng, Yuanjin Zheng, Pratik Chattopadhyay, Lipo Wang
- 掲載：Technologies（MDPI）, Vol. 13, Issue 1, Article 32（2025年1月12日公開）
- URL：https://www.mdpi.com/2227-7080/13/1/32
- DOI：https://doi.org/10.3390/technologies13010032
- ライセンス：Open Access（CC BY 4.0）。誰でも無料で読めます

### 1. 論文の要約

**どんな話か**
- Transformer はもともと文章のためのモデル。2020年に、これを画像にそのまま使う **ViT** が登場した。
- この論文は、ViT とその改良版を「画像分類」にしぼって整理し、CNN と数字で比べている。

**ViT のしくみ（ざっくり）**
1. 画像を 16×16 ピクセルなどのタイル（パッチ）に切る
2. タイルを、文章の「単語」のように1列に並べる
3. **Self-Attention**（自己注意）で、どのタイルとどのタイルが関係しているかを全部いっぺんに計算する
4. 最後に「これは何の画像か」を答える

- CNN は「近くのピクセル」しか一度に見られない。ViT は最初から画像全体の関係を見られるのが強み。

**ViT の弱点**
- **データをたくさん必要とする**
  - CNN には「近くのピクセルは関係が深い」という前提（帰納バイアス）が最初から入っている
  - ViT にはその前提がないので、自分で学ぶためにデータがたくさんいる
  - ImageNet（130万枚）だけで学習すると、CNN（ResNet）と同じくらいの精度しか出ない
  - JFT-300M（3億枚）で事前学習すると、CNN を上回る
- **計算が重い**：パラメータ数・計算量が大きい

**改良の方向（論文の 3 章）**

| 方向 | 何をするか | 代表的なモデル |
| --- | --- | --- |
| データ効率を上げる | 少ないデータでも学習できるようにする | DeiT（先生モデルから教わる「蒸留」）、T2T-ViT |
| CNN の考えを混ぜる | 畳み込みで「近く」を見る力を足す | CPVT、VT、CvT、CeiT、Refiner、UniFormer |
| 軽くする | スマホなどでも動くように小さく・速くする | LeViT、CCT |
| 深くする | 層を増やしても学習が崩れないようにする | CaiT、DeepViT |
| 入れ子・クロスアテンション | 大きさの違う特徴を組み合わせる | NesT、CrossViT |
| その他 | 損失関数の工夫、構造の一般化 | Patch-wise Loss、MetaFormer |

**比べた結果（論文の 4 章の表から）**
- **ImageNet だけで学習した場合**（Top-1 精度）
  - ViT-B/16：77.9%、ViT-L/16：76.5%
    - 大きいモデル（L）のほうが低い＝データが足りないと大きいモデルは活かせない
  - DeiT-B：81.8%（ViT-B と同じ大きさで +3.9 ポイント）
  - CNN の ResNet-50：76.2%、EfficientNet-B5：83.6%
  - 一番高いのは CvT-W24（87.7%）だが、計算量は193G FLOPs ととても重い
- **小さいデータ（CIFAR）でゼロから学習した場合**
  - CCT-7/3x1：パラメータ376万個で CIFAR-10 94.72%
  - ResNet1001-v2（1,033万個）の95.08%とほぼ同じ精度を、約3分の1のパラメータで出している
- **事前学習してからファインチューニングした場合**
  - ViT系は CIFAR-10 で99%前後、Flowers で99%前後と非常に高い
  - Stanford Cars は90〜94%と、ほかより低め（論文1の「Cars は似ていないので転移しにくい」と一致）

**課題と今後**
- 課題
  - 医療画像や交通解析など、特定の分野ではまだあまり使われていない（データが少ないため）
  - 軽さと精度の両立がまだ難しい
- 今後
  - 畳み込みと組み合わせる
  - 正規化・損失関数・ハードウェアに合わせた設計を工夫する
  - CLIP のように**画像と文章をセットで学習**して、人手のラベルに頼らないようにする

### 2. 歴史・流れ

| 年 | できごと | ポイント |
| --- | --- | --- |
| 2017 | Transformer 登場（Attention is All You Need） | 翻訳のためのモデル。Attention で文全体を一度に見る |
| 2018〜2019 | BERT、RoBERTa | 文章の分野で Transformer が主流に |
| 〜2019 | 画像は CNN の時代 | ResNet（2016）、EfficientNet（2019）など |
| 2020 | **ViT** 登場 | 畳み込みを使わず、Transformer だけで画像分類に成功。ただし大量のデータが必要 |
| 2021 | DeiT、T2T-ViT | ImageNet だけでも学習できるように（データ効率の改善） |
| 2021 | CvT、CeiT、CPVT、LeViT、CCT、CaiT、DeepViT、CrossViT など | CNN との組み合わせ、軽量化、深層化が一気に進む |
| 2021〜2022 | NesT、MetaFormer、CLIP | 構造の見直し、画像と文章のセット学習 |
| 2023〜 | 医療画像の分割、画像融合、物体追跡などへ応用 | 画像分類以外にも広がる |

### 3. 社会的課題とのつながり
- **医療画像**
  - 病変の分類や、臓器の領域を切り出す処理に使われ始めている（論文 3.4.7 節）
  - ただしデータが少なく、ViT の「データをたくさん必要とする」弱点が問題になる
- **交通解析・監視**
  - 物体の追跡（Multi-Object Tracking）への応用（3.12 節）
  - 可視光カメラと赤外線カメラの画像を合成して、暗い場所や悪天候でも見えるようにする研究（3.4.8 節）
- **スマホ・組み込み機器**
  - LeViT・CCT のような軽いモデルなら、高性能なサーバーがなくても動かせる
  - 電力の削減にもつながる
- **ラベル付けの人手不足**
  - CLIP のように、ネット上の「画像＋説明文」から学べば、人が1枚ずつラベルを付ける手間を減らせる

## 2本を通してわかること（ミニ研究へのヒント）

- **共通のメッセージ：大きいモデルほど、データの量と「似ている度合い」が大事**
  - 論文1：転移学習は、ソースとターゲットが似ていないとうまくいかない
  - 論文2：ViT は、データが少ないと CNN に勝てない
- **両方の論文に出てくるデータセット**：ImageNet、CIFAR-10/100、Oxford Pets、Flowers、Stanford Cars
  - 信頼性が高く、比べる材料も多いので、ミニ研究で使いやすい
- **両方で「Stanford Cars は難しい」という結果が出ている**
  - ImageNet と似ていないデータの代表
- **ミニ研究の問いの案**
  - 「身近だけれどラベル付きデータが少ない画像（例：食事の写真 = Food-101）で、CNN と ViT のどちらを、どう転移学習すれば一番よく当たるか？」
  - 資料 p.6 の「食事記録や健康管理の手間をどう減らせるか？」につながる
  - データ量を減らしていったとき、CNN と ViT の差がどう変わるかを見れば、2本の論文の主張を自分たちで確かめられる
